# Suggesly

Suggesly is a React CRM workspace with dashboard, deals, accounts, and contacts views, plus an Express/Mongoose backend scaffold.

## Scripts

- `npm start` starts the React frontend.
- `npm run backend` starts the backend API.
- `npm run backend:dev` starts the backend with nodemon.
- `npm run dev` starts frontend and backend together.
- `npm run build` creates a production frontend build.
- `npm test` runs the React test suite.

## Project Structure

- `src/` contains the React app.
- `src/layout/` contains shared layout components.
- `src/pages/` contains page-level CRM views.
- `src/data/` contains mock table data used by the frontend.
- `backend/src/` contains the Express API, services, models, views, and database config.
- `public/assets/` contains app-owned public image assets.
